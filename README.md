# Последний в особняке 🎃

Мобильная Halloween-игра для 4–7 игроков на одном iPhone. Атмосфера: хоррор, чёрный юмор, мистика и интриги.

## Запуск веб-версии

Проект — PWA: откройте сайт в Safari и добавьте его на экран «Домой». Игровой движок и сценарии работают локально, без обязательного сервера.

## Локальная разработка

```bash
npm install
npm run dev
```

## iOS

iOS-оболочка построена на Capacitor. На macOS с Xcode:

```bash
npm install
npm run build
npx cap sync ios
npx cap open ios
```

GitHub Actions собирает web/PWA и архив iOS-проекта. Для подписанного IPA потребуются защищённые GitHub Actions Secrets с Apple Distribution certificate (.p12), паролем сертификата и provisioning profile. Не добавляйте сертификаты, ключи или пароли в репозиторий.

## Приватность ролей

- Роль отображается только после явного нажатия «Получить роль».
- После подтверждения «Я запомнил роль» экран закрывается и передаёт телефон следующему игроку.
- При уходе приложения в фон приватный экран скрывается.
- Назад к уже просмотренным ролям вернуться нельзя.
- Данные игры хранятся локально на устройстве.

> Защита от случайного просмотра не может предотвратить фотографирование экрана другим устройством.

## Технологии
