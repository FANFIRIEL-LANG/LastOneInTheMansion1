# Offline narrator recordings

Place the approved Russian narrator MP3 files in this folder using the exact filenames below. The app loads them locally; no network connection or cloud TTS is used during gameplay.

- narrator_welcome.mp3
- narrator_house.mp3
- narrator_rules_public.mp3
- narrator_day_start.mp3
- narrator_day_actions.mp3
- narrator_event_blood_moon.mp3
- narrator_event_basement.mp3
- narrator_event_portrait.mp3
- narrator_event_vote.mp3
- narrator_trial.mp3
- narrator_night.mp3
- narrator_cult_whisper.mp3
- narrator_dawn.mp3
- narrator_attack_blocked.mp3
- narrator_no_attack.mp3
- narrator_guests_win.mp3
- narrator_cult_win.mp3
- narrator_restart.mp3

Recommended: MP3, 44.1 kHz, 128–192 kbps. Keep a consistent loudness and voice across all files. Do not put secret roles, private clues, player names, or night targets in public narration.

Until the MP3s are added, the game uses the browser's Russian speech voice as a temporary fallback.
